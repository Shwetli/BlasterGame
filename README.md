# BlasterGame

Мултиплейър игра от жанра TPS, разработена с Unreal Engine 5 и C++.

## Изисквания
- Unreal Engine 5.1
- Visual Studio 2022
- Steam клиент

## Стартиране от изходен код
1. Клонирай хранилището
2. Десен клик върху `Blaster.uproject` → Generate Visual Studio project files
3. Компилирай във Visual Studio 2022
4. Натисни Play в Unreal Editor

## Стартиране на пакетираната версия
1. Отвори Steam
2. Стартирай `Blaster.exe`
3. Host или Join

## Пакетирана версия
Пакетираната версия на играта е налична в Google Drive директорията на проекта.

!!! За да работи пакетирания проект трябва да се изтегли цялата папка Windows в Build папката!!!
